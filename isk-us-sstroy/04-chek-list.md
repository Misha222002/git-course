# Чек-лист к иску ООО «УС» против ООО «СЗ «ССТРОЙ»

Отмечать по мере сбора. Пункты с пометкой **блокер** закрываются до подачи, иначе иск оставлят без движения, без рассмотрения либо просительная часть окажется неверной.

## 1. Реквизиты и текст сделки

| № | Документ / действие | Статус |
|---|---|---|
| 1.1 **блокер** | Полное наименование, ИНН, ОГРН, КПП, юридический и почтовый адреса, телефон, e-mail Истца | ☐ |
| 1.2 **блокер** | То же в отношении Ответчика; сверить краткое имя «ООО «СЗ «ССТРОЙ»» с ЕГРЮЛ | ☐ |
| 1.3 **блокер** | Полный Договор от 15.01.2024 со всеми пунктами, приложениями, листами подписи | ☐ |
| 1.4 | Проверить: неустойка, подсудность, претензионный срок, запрет уступки, условия о регистрации | ☐ |
| 1.5 **блокер** | Акт приёма-передачи (если составлялся) | ☐ |
| 1.6 **блокер** | Категория земель, ВРИ, адрес / описание местоположения участка | ☐ |

## 2. ЕГРН и «чистота» участка

| № | Документ / действие | Статус |
|---|---|---|
| 2.1 **блокер** | Актуальная выписка ЕГРН об объекте и о переходе прав | ☐ |
| 2.2 **блокер** | Правообладатель = Ответчик? Если нет — переписать просительную часть | ☐ |
| 2.3 **блокер** | Ипотека, арест, аренда, сервитут, запрет регистрации | ☐ |
| 2.4 **блокер** | Последующая продажа третьему лицу после 15.01.2024 | ☐ |
| 2.5 | Дата и номер записи о переходе права к Ответчику — внести в иск вместо прочерков | ☐ |
| 2.6 | Проектная декларация и ДДУ по МКД позиции 13 (наш.дом.рф / ЕИСЖС) | ☐ |

Если в ЕГРН право **не переходило** к Ответчику: исключить истребование участка и формулировку «неосновательно приобретённого»; оставить расторжение и, при необходимости, запрет требовать регистрации перехода.

Если есть **ипотека банка** или **зарегистрированные ДДУ**: не подавать иск в текущей редакции; привлечь банк / дольщиков и оценить переход на взыскание цены.

## 3. Неоплата и эскроу

| № | Документ / действие | Статус |
|---|---|---|
| 3.1 **блокер** | Выписка по расчётному счёту Истца за период с 15.01.2024 по дату подачи | ☐ |
| 3.2 | Бухгалтерская справка об отсутствии задолженности покупателя как актива / о нулевой оплате | ☐ |
| 3.3 | Запрос в уполномоченный банк объекта и ответ об отсутствии эскроу-счетов | ☐ |
| 3.4 | Сведения с наш.дом.рф: объект не введён / счета не раскрывались | ☐ |

Бремя доказывания оплаты лежит на покупателе, но суд ожидает минимального подтверждения и от продавца.

## 6. Заполнение прочерков в иске

Внести в `02-iskovoe-zayavlenie.md` и `03-hodataystvo-ob-obespechenii.md` после сбора документов:

- ОГРН, ИНН, адреса, контакты сторон;
- адрес (местоположение), категория и ВРИ участка;
- реквизиты акта передачи и записи ЕГРН;
- номер Договора, если он есть помимо даты;
- Ф. И. О. и должность подписанта.
