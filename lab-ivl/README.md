# Лабораторная работа: Искусственная вентиляция лёгких

Проектирование медицинского аппарата **«РеспироПВ-2»** с принудительно-вспомогательными режимами ИВЛ (SIMV / P-SIMV) в стационарном и портативном исполнениях.

## Состав материалов на сдачу

| Файл | Назначение |
|------|------------|
| `Отчет_лабораторная_ИВЛ.docx` | Полный отчёт студента (этапы А–Г) |
| `Спецификация.md` | Спецификация эскизного проекта |
| `diagrams/` | Рисунки и эскизные схемы |
| `presentation/index.html` | Презентация для защиты |

## Как пересобрать

```bash
python3 lab-ivl/generate_diagrams.py
python3 lab-ivl/generate_report.py
```

- Методическое пособие И.Н. Белозеровой (МАИ, 2010)
- Задание к лабораторной работе «Искусственная вентиляция легких»
